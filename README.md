# UK Weather Map

A 3D map of the British Isles in Three.js, which will show Met Office UKV forecast data with realistic graphics.

So far it renders the terrain: elevation, a coastline-accurate sea, sky, and sun lighting, with a vertical exaggeration
slider. The weather layers are not wired in yet; see [`pipeline/README.md`](pipeline/README.md) for the data side.

## Running it

```
npm install
npm run dev      # local dev server
npm run build    # type-check and build static files into dist/
```

## Coordinates

The scene uses the same Lambert Azimuthal Equal Area projection as the UKV 2 km grid
(`+proj=laea +lat_0=54.9 +lon_0=-2.5 +ellps=GRS80`), in kilometres: X is easting, Z is minus northing, Y is
height. Terrain vertices fall exactly on UKV cell centres, so weather grids can be draped over the terrain with no
resampling. `src/projection.ts` converts between lon/lat and world coordinates.

## Terrain data

`public/data/uk-heightmap.png` (Terrarium-encoded, `height = R * 256 + G + B / 256 - 32768` metres) and its JSON
sidecar are generated by `scripts/build_heightmap.py` from
[AWS Terrain Tiles](https://registry.opendata.aws/terrain-tiles/), with the land/sea split taken from
[Natural Earth](https://www.naturalearthdata.com/) 10m land. They are committed, so you only need to rebuild them
to change the extent or resolution:

```
pip install -r scripts/requirements.txt
npm run heightmap
```
